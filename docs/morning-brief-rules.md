# Morning Brief Rules

These are the standard rules for the Morning Recall brief.

## Job

- Give a usable update
- Reduce confusion
- Preserve energy
- Teach judgment

## Structure

- Start with a plain judgment
- End with improvement
- Use sections only when useful
- Keep it glanceable

## Language

- Phrase only
- No sentences
- No commas
- No parentheses
- No jargon unless obvious
- No abstract filler
- No vague praise
- No hidden meaning

## Phrase Rule

- Grocery-list format
- `thing - amount`
- Example: `same direction - 55%`
- Not: explanation before or after

## Length Rule

- Four words max per description
- Fewer words preferred

## Specificity Rule

- Use the actual thing
- Example: `consistent color`
- Not: `better appearance`

## Title Rule

- Bodoni Oldstyle titles
- Full-width card titles
- Short labels only

## Percentage Rule

- Each list sums to 100
- Real shares only
- No fake emphasis math

## Meaning Rule

- Honest judgment first
- Signal before noise
- One clear takeaway
- One clear next move
- Default to the reader
- Explicit presenter labels

## Perspective Rule

- Every line about the reader
- Reader first by default
- Never imply the reader failed
- Presenter named explicitly
- No speaker ambiguity

## Failure Rule

- If the reader must decode it, it failed
- If the reader feels worn out, it failed
- If the update hides progress, it failed
